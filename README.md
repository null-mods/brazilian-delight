# Brazilian Delight

Addon for [Farmer's Delight](https://modrinth.com/mod/farmers-delight) bringing Brazilian crops, dishes and drinks.

- Minecraft 1.21.1
- NeoForge 21.1.265+
- Farmer's Delight 1.3.0+

## Development

Requires JDK 21.

```
./gradlew runClient   # dev client with Farmer's Delight loaded
./gradlew runData     # data generators -> src/generated/resources
./gradlew build       # jar in build/libs
```
