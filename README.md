# Brazilian Delight

Addon for [Farmer's Delight](https://modrinth.com/mod/farmers-delight) bringing Brazilian crops, dishes and drinks.

- Minecraft 1.21.1
- NeoForge 21.1.265+
- Farmer's Delight 1.3.0+

## Bug reports

Found a bug? Open an [issue](https://github.com/null-mods/brazilian-delight/issues) with:

- Minecraft, NeoForge, Farmer's Delight and Brazilian Delight versions
- What happened and what you expected
- Steps to reproduce
- The crash report or `latest.log`, if there is one (as a file or a link, e.g. [mclo.gs](https://mclo.gs))

## Contributing

Only **art** contributions are accepted: items and blocks.

**AI-generated art is not accepted.** Every texture must be drawn by hand, pixel by pixel. 

- 16x16 pixel art, following the Farmer's Delight style (dark outline, few tones, light from the top left)
- Color palettes used in the mod are in [`palettes/`](palettes)
- Send a PNG through an [issue](https://github.com/null-mods/brazilian-delight/issues) or a pull request adding it to `src/main/resources/assets/brazilian_delight/textures/`
